# wraiting

An agent skill for writing text that instructs or supplies context to an AI: skills, specifications, plans, prompts, tool descriptions, and runtime context templates.

It aims for minimal sufficient context: dense, authoritative instructions that keep each statement's status and scope, carry no narration or history, and are checked against the behavior they should produce.

## Install

```sh
npx skills add apurin/wraiting
```

Then ask your agent to write, review, or tighten AI-facing text. The guidance is in [SKILL.md](SKILL.md).
